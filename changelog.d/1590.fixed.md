- **`tan build --build-root DIR` no longer refuses a `planPathMode: tokened`
  plan.** The `${PROJECT_ROOT}` guard compared the board.yaml directory with
  the build root, so any `--build-root` elsewhere failed with
  `build.project-root-mismatch` although `--build-root` only moves the output
  (tan-cli#1590). The check is removed, and the code with it: the build root
  defaults to the board.yaml directory, the planner tokenizes every project
  path, and a relative `appDir` already fails loudly before dispatch.
