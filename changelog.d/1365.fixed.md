- **The code-review-graph pre-commit hook no longer hangs commits in `git
  worktree` checkouts.** Older code-review-graph releases wrote an unguarded
  hook that ran a full graph build in every linked worktree. `scripts/install-crg-hook.sh`
  installs a worktree-skipping, `timeout`-bounded block (per-machine, run once
  per clone), and `.code-review-graph/` is now gitignored.
