- **A sysbuild Zephyr slice now wires its per-core `alp.conf` into the
  application image.** `python/tan/planner/orchestrator.py` emitted no
  `EXTRA_CONF_FILE` for a `boot:` / `security.psa:` (sysbuild) slice, relying
  on each example's `CMakeLists.txt` bridge, which alp-sdk#866 retires. It now
  emits `-D<image>_EXTRA_CONF_FILE=<buildDir>/alp.conf`, with `<image>` the
  basename of the app directory handed to `west build`, mirroring alp-sdk's
  `scripts/alp_orchestrate/orchestrator.py`.
