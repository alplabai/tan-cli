- **`tan flash` gains a `linux_mtd` backend that deploys a V2N / V2N-M1 CM33 image
  over the running Linux on the A55.** It scps the image to the board, checks the
  named partition in `/proc/mtd`, runs `flash_erase` + `flashcp`, reads the
  partition back and compares a sha256, then removes its temp file. The host comes
  from `flash_args.host` or `--target-host`; `flash_args.flash_partition` is
  required and never defaulted, `mtd0` is always refused, and `--partition` must
  agree with the manifest. ssh/scp run with `BatchMode=yes`. The envelope records
  every step and the digest comparison and carries a `followUp` that a remoteproc
  restart or reboot is needed to run the new image (tan does neither). New codes
  `flash.linux-mtd-*`; see `docs/linux-mtd.md`. Not yet validated on silicon.
