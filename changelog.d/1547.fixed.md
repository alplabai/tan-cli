- **`tan bootstrap` now says when a checkout it moves may strand another project's `.alp/sdk-path`.** Run from outside a project (for example the parent of `proj/` and `alp-sdk/`), bootstrap resolved the checkout by discovery, moved it, and rewrote only a pin it had resolved through itself, so a project that `tan init --sdk-root` had pinned to the old path silently dropped to the `globalDefault` tier. tan keeps no list of the projects that pin a checkout, so every relocation now also reports `bootstrap.relocated-pins-stale` (a warning, exit code unchanged), naming the vacated path and the new one an affected `.alp/sdk-path` `sdkPath` must be changed to (tan-cli#1547).
