- **`tan flash --ram --core m55_he` and `tan probe --core m55_he` pin the M55-HE access port on the Ensemble E8.** J-Link's own AP scan attached to the first M55 it found, which is the HP's `0x00200000` when the resident image keeps the HP powered, so the RAM-run was refused with `flash.ram-core-mismatch` and could not be used on such a module at all. On E8 silicon (`alif:ensemble:e8` from the SDK metadata) the J-Link preamble now declares the HE AHB-AP with its address and pins it before `connect`. The core check reads the pinned address from the echoed command only when J-Link's banner confirms it used the user-specified AP map, and tags it `ap.apAddrSource: "pinned"` (else `"scanned"`); the ITCM comparison is then the identity evidence. Other silicon keeps J-Link's scan (tan-cli#1566).
