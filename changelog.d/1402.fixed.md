- **`tan size` no longer reports a false over-budget RAM for a `diagnostics.link: itcm` image with SRAM0-staged data** (tan-cli#1402). RAM summed every writable section whatever its address, so model data linked into SRAM0 was charged against the core's 256 KB DTCM budget (378195/262144 for an image whose link map says 93988 B). Writable sections placed in the SRAM0 aperture are now left out of RAM, for both the size tool and the section-header reader.
