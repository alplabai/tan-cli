`version_check` no longer counts `bump_dev_version`'s automated `TAN_VERSION moved to ...` bullet as content for a stable tag's `CHANGELOG.md` section, so `v0.7.0` cannot publish with only that bullet and no BREAKING preamble; `docs/release-contract.md` now points at the `## [0.7.0-rc1]` preamble that GA must carry over. The `clean host (freeze): all legs` aggregator now reads the Linux leg's result on `pull_request` instead of stub-passing, and `scripts/e2e-container.sh` pulls its harness image through `scripts/ci/docker-pull.sh` (tan-cli#1524). A stable tag now also refuses a section that still carries the bot bullet, and `scripts/e2e-container.sh` uses a locally cached image and falls back to the bare ref instead of aborting when the mirrors cannot serve it.
