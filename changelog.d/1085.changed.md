- **`tan/planner/template.py`'s curated-error register grows one more shared
  primitive, and shrinks.** `render_to_envelope`'s template-example
  `board.yaml` read carried its own hand-written `except (OSError,
  UnicodeDecodeError)` block, byte-for-byte the same shape
  `document_guards.DocumentGuards.read_catalog_document` already used for the
  catalog's own read -- two definitions of "cannot read `<what>` at `<path>`:
  `<reason>`" that happened to still agree. Both now call a new
  `DocumentGuards.require_readable_text(path, *, what)`, with the message
  text unchanged. `_require_mapping_doc`/`_require_field`/`_require_key`
  (tan-cli#1073/#1082) and the catalog readers themselves (tan-cli#1084) were
  already on the shared register before this change; `_require_constraints`
  and the three single-caller YAML readers (`_load_som_doc`,
  `_board_route_entries`, `_docs_ref`) stay local, on purpose -- each still
  has no second caller to prove the sharing.
