- **`tan bootstrap` installs its own Zephyr SDK even when the pinned version is
  already on the host.** `west sdk install` ignores `--install-dir` when it can
  find that version anywhere it searches (`~/zephyr-sdk-<ver>`, its `bin` dir on
  `PATH`, a CMake registry entry), so the SDK base never reached tan's store and
  `toolchain-install` failed with a remedy that looped. West now runs with a
  scratch `HOME`, the SDK location variables blanked, and SDK roots dropped from
  `PATH` / `CMAKE_PREFIX_PATH`; on Linux and macOS this also stops it leaving a
  `~/.cmake/packages/Zephyr-sdk` entry for a deleted `.tmp-*` directory. A reuse
  tan cannot hide (`/usr`, `/usr/local`, `/opt`, Windows' HKCU registry) is
  refused by name before the toolchain download (tan-cli#1552; Windows registry
  follow-up tan-cli#1553).
