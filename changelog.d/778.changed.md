- **`scripts/alp_cli/model.py` leaves the planner-relocation freshness gate's
  `HAND_PORT_HASHES` table.** ADR-0028 relocated the host-side model engine
  into `tan.model`, and alp-sdk is deleting its own `scripts/alp_model/` and
  `scripts/alp_cli/model.py` originals -- there is no upstream file left for
  this entry to pin, so it is removed rather than left to drift stale. The
  other eighteen `HAND_PORT_HASHES` entries are untouched, each still
  measured at its own pin; the class-level weakness in how this table is
  audited was tracked separately as tan-cli#778, and is closed on `dev` by
  `python/tests/gates/test_hand_port_tan_side.py` -- not by this change.

  `python/pyproject.toml` also gains a `model-compile` extra
  (`ethos-u-vela>=3.9`, `tflite>=2.10`, `flatbuffers>=23.1.21`), mirroring
  alp-sdk's own extra of the same name pin-for-pin: `tan.model.adapters.
  ethos_u`'s own docstring already named "the `model-compile` optional
  dependency", but nothing in `python/pyproject.toml` declared it until now.
  It is optional, same as `model-io` -- a bare `pip install alp-tan` still
  installs and runs; only the Vela compile path needs it.
