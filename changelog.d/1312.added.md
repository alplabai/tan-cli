- **`tan flash` takes `--probe-serial <SN>` and `--probe-usb-path <bus-port>` to
  pick the J-Link a Flow D (`alif_mram_jlink`) write goes to, and refuses rather
  than guess.** Both override `flash_args.jlink_serial` for the run and are
  echoed as `probe` on the entry (also under `--dry-run`, which reports the
  would-be selection). J-Link Commander selects by serial only, so a USB path is
  resolved to the serial sysfs reports for that port; when other visible probes
  share it (every probe on the Alp Lab bench does) tan cannot address one of
  them and refuses with the new `flash.probe-ambiguous`, naming the colliding
  paths. Several probes visible with no selector, or several sharing the
  selected serial, refuse the same way before any write.
  `flash.probe-not-found` and `flash.probe-selector-conflict` cover a selector
  that matches nothing or two that disagree. Run tan where a wrapper has masked
  every other probe (one probe visible) and the shared serial is unambiguous; if
  the wrapper stands in for `JLinkExe` instead, `TAN_PROBE_ISOLATED=1` asserts
  the isolation. Enumeration is read-only sysfs and Linux only.
