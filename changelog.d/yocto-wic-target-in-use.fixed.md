- **`tan flash` refuses a `yocto_wic` target that is in use on the host.** A mistyped `flash_args.target` (`/dev/sda`) passed the block-device check and `dd` overwrote the workstation's root disk. The real write now refuses a target that is mounted or swap (`/proc/self/mountinfo` maj:min resolved through `/sys/dev/block`, `/proc/swaps`), that the kernel holds in ANY mount namespace (`open(O_RDONLY | O_EXCL)` on the device and each partition returns `EBUSY` -- so a container handed the host's `/dev/sdX` is covered), or that has `holders` (opened LUKS, assembled md, an LV in use), with the new `flash.yocto-wic-target-in-use`. The target is identified by device number, so a `mknod` alias or a real-node `/dev/root` still matches. It fails closed: when the mount table, `/proc/swaps`, sysfs or the claim probe cannot be read the target is refused. **A real `yocto_wic` write on macOS or Windows is therefore now always refused** (no `/sys/dev/block`); `--dry-run` previews are unaffected. Ported from alp-sdk#3085 and kept behaviourally identical to alp-sdk's `_require_unused_device`.
