- **`tan bootstrap` removes the CMake package-registry entries its own
  temporary install directories left behind.** `west sdk install`'s
  `setup.sh -c` / `setup.cmd -c` registers the `.tmp-*` directory it installed
  into, and tan then moves that directory into its store, so the entry pointed
  nowhere. Every run now prunes the `Zephyr-sdk` entries whose path is one of
  tan's own `<toolchain root>/zephyr-sdk-*.tmp-*/cmake` directories --
  `~/.cmake/packages/Zephyr-sdk/` on Linux and macOS (residue from runs before
  tan-cli#1552), `HKEY_CURRENT_USER\Software\Kitware\CMake\Packages\Zephyr-sdk`
  on Windows, which no environment variable redirects. An entry's name is the
  MD5 of its path, so a registration the user made is never touched
  (tan-cli#1553).
