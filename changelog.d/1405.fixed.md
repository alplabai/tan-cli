- **`tan flash`, `tan size` and `tan image` accept the same `--build-root X` that `tan build` does** (tan-cli#1405). `tan build --build-root X` writes `X/build/system-manifest.yaml`, but the consumers only looked at `X/system-manifest.yaml`, so the same value failed with `flash.manifest-not-found`. They now try `X/system-manifest.yaml` first, then `X/build/system-manifest.yaml`, and a miss names both paths.
