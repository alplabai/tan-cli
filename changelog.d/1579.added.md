- **`tan build --core-define CORE:NAME=VALUE` gives one core its own `-D` in a single run.** Repeatable, planned builds only, applied after any plain `-D` to that Zephyr slice alone (`--core-define m55_hp:SHIELD=a --core-define m55_he:SHIELD=b`), so a two-core project no longer needs two `--core` invocations whose second run wipes the first slice for a missing `-D` (tan-cli#1382). The per-slice stamp records each core's own set; the envelope reports them under `data.coreDefines`. Plain `-D` / `--core` are unchanged.
