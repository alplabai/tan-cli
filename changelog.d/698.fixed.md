- **README's `### What a build needs` now has a real Windows row, not just
  Linux and macOS.** #687 added the section but only ever enumerated `git`,
  `cmake`, `python3`, `ninja`, `xz`, `wget` on Linux and the shorter macOS
  subset; a reader on Windows -- a supported host with its own installer and
  CI leg -- found nothing there for them. The section is now a per-OS list
  with Linux, macOS, and Windows as siblings, and the Windows row (`git`,
  `cmake`, `python`, `ninja`) is read straight off the three in-repo sources
  that already agreed on it: alp-sdk's `metadata/bootstrap.json`
  `prerequisites.windows`, `tan.core.bootstrap.fallback_facts()
  .prerequisites_windows`, and `contract/fixtures/bootstrap/manifest.json`.
  The `west sdk install` follow-on note is also now scoped correctly: `file`
  (Linux/macOS only) had drifted into reading as a global requirement when
  the section was restructured into per-OS siblings; native Windows instead
  needs 7-Zip on `PATH` for `west`'s `.7z` extraction, which is documented,
  along with the fact that 7-Zip sits only in the SDK's install-command map
  and not its required tool list, so `tan doctor` will not itself flag it as
  missing.
  `tests/gates/test_readme_install_prerequisites.py`'s build-list check now
  covers all three OS lists (`prerequisites_posix`/`_macos`/`_windows`), not
  just POSIX, so a future placeholder or drift in any of them fails the gate
  instead of passing silently. (#698)
